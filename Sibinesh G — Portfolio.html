Projects

🔥 Fire Detection using OpenCV

Python · OpenCV · Computer Vision

A real-time computer vision application that watches a live camera feed for fire and smoke. It compares consecutive frames to detect motion, isolates changed regions using contour detection, and identifies possible fire based on characteristic red-channel intensity.

A low-light branch switches to a dedicated night-mode detection path. When fire is detected, the system sounds an alert, saves the triggering frame, and automatically records a short video clip.

🌐 Idiom Translation using NLP

Python · Streamlit · Hugging Face Transformers · Deep Translator

An NLP pipeline that takes English sentences containing idioms and makes them easier to translate. It detects idioms using a dataset of 2,000+ entries, matches the longest phrase first, and replaces idiomatic expressions with their plain-English meanings.

The processed sentence is then paraphrased into a natural sentence and translated into Tamil or another supported language. The project supports both an NVIDIA NIM-hosted LLM backend and an offline Hugging Face + Google Translate pipeline.
